# Фронтенд 2 команды

## Особенности стека
- ⚛️ React 19 с TypeScript
- 🎨 MUI (Material UI) компоненты
- 📦 Webpack 5 с горячей перезагрузкой
- 🔧 TypeScript с поддержкой последних фич
- 🎯 ESLint + Prettier для code quality
- 🎭 SCSS/CSS Modules для стилей
- 🛡 Защищенные маршруты с проверкой прав доступа 
- 🔐 Система аутентификации и роутинга

## Установка зависимостей
```
npm install
```

## Запуск приложения в режиме разработки с hot-reload.
```
npm start
```
- Очищает build директорию
- Создает тег версии
- Запускает линтинг
- Запускает webpack dev server

## Нюансы
- Все коментарии вида // оставлены не просто так, а чтобы на них обритили внимани и возможно использовали в дальнейшем то что закоменчено
- Замечания при сборке оставлены специально. Убедитесь что ваша среда подсвечивает warning-и inline стилей и errors при неправильной расстановке import-ов в компонентах. Если это не так, скорее всего поможет перезагрузка среды после установки зависимостей
